## 🧠 Key Concepts Learned

### Variables

Variables are used to store data.

```java
int age = 20;
String name = "Vamshi";
```

### Data Types

| Data Type | Purpose          |
| --------- | ---------------- |
| `int`     | Whole numbers    |
| `double`  | Decimal numbers  |
| `char`    | Single character |
| `boolean` | `true` / `false` |
| `String`  | Text             |

### Scanner

`Scanner` is used to take input from the user.

```java
Scanner sc = new Scanner(System.in);
```

Examples:

```java
String name = sc.next();
int age = sc.nextInt();
```

### Arithmetic Operators

```text
+  Addition
-  Subtraction
*  Multiplication
/  Division
```
